# MSA-3-NovaMarket

Проектная работа третьего спринта «Микросервисная архитектура».

| Каталог | Содержание |
| --- | --- |
| `Task1` | Event-driven архитектура, Saga-хореография оформления заказа, реестр и UML-диаграммы. |
| `Task2` | Архитектура истории покупок и ADR выбора способа чтения. |
| `Task3` | Манифесты Kubernetes, HPA, Locust-сценарий и инструкция для подтверждения масштабирования. |
| `Task4` | Конфигурации NGINX для Rate Limiting и защиты внешней логистики. |

Диаграммы сохранены в исходном формате PlantUML (`.puml`), чтобы их можно было открыть и отрендерить в IDE или на сервере PlantUML.
