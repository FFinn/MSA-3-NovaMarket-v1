# MSA-3-NovaMarket

Проектная работа третьего спринта «Микросервисная архитектура».

| Каталог | Содержание |
| --- | --- |
| `Task1` | Событийная архитектура, Saga-хореография оформления заказа, реестр и UML-диаграммы. |
| `Task2` | Архитектура истории покупок и архитектурное решение по способу чтения данных. |
| `Task3` | Манифесты Kubernetes, HPA, Locust-сценарий и инструкция для подтверждения масштабирования. |
| `Task4` | Конфигурации NGINX для ограничения частоты запросов и защиты вызовов к логистике. |

Диаграммы Task1 и Task2 доступны в двух вариантах: исходники PlantUML (`.puml`) и PNG.
При разночтении источником истины считается исходник PlantUML.

В `Task3/evidence` лежат результаты прогона в Minikube: логи HPA, события Kubernetes, скриншот дашборда и отчёт Locust.
